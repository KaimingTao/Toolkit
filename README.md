# Toolkit

A small collection of browser-based utilities. Each tool is self-contained and runs locally in a web browser without a build step.

## Web tools

| Tool | Description | Open |
| --- | --- | --- |
| Countdown Timer | Set a countdown and receive an alert or browser notification when it finishes. | [Launch](https://kaimingtao.github.io/Toolkit/web/timer/) · [Source](web/timer/) |
| Right Now | Display and copy the current local timestamp in `YYYY-MM-DD HH-MM-SS` format. | [Launch](https://kaimingtao.github.io/Toolkit/web/timestamp-now/) · [Source](web/timestamp-now/) |

Browse all web tools from the [web tools index](https://kaimingtao.github.io/Toolkit/web/).

## Run locally

Open a tool's `index.html` file in a browser. No dependencies or installation are required.
