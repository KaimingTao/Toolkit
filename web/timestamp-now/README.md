# Right Now

A minimal browser tool for viewing and copying the current local timestamp.

## What it does

- Displays the current time in `YYYY-MM-DD HH-MM-SS` format.
- Uses the time zone reported by the browser.
- Updates automatically as time passes.
- Copies the current timestamp to the clipboard with one click.
- Produces a filename-friendly value without colons.
- Includes Minimal, Airport Flip Board, and Nixie display styles.
- Remembers the selected display style between visits.

## Use it

Open [`index.html`](index.html) in a browser, or [launch the hosted tool](https://kaimingtao.github.io/Toolkit/web/timestamp-now/).

No installation or dependencies are required.
