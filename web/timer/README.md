# Countdown Timer

A self-contained browser countdown timer.

## What it does

- Accepts a duration in hours, minutes, and seconds.
- Starts, pauses, resumes, and resets the countdown.
- Shows a completion message when time runs out.
- Can send a browser notification when permission is granted.
- Keeps the remaining time accurate when the tab is in the background.

## Use it

Open [`index.html`](index.html) in a browser, or [launch the hosted tool](https://kaimingtao.github.io/Toolkit/web/timer/).

No installation or dependencies are required.
